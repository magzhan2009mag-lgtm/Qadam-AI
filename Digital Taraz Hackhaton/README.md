# Qadam AI

**ИИ-платформа для малого бизнеса Тараза**: принимает заказы и записи в чате, проверяет качество обслуживания, разбирает отзывы и подсказывает владельцу, как зарабатывать больше. Работает на русском и казахском, потери и рост показывает в тенге.

*Хакатон Zhambyl Hub · трек «AI for SME & Local Business»*

## Для жюри коротко

- **Проблема:** малый бизнес теряет деньги там, где этого не видно: не предложили допродажу, не ответили клиенту, не заметили отзыв.
- **Решение:** пять ИИ-модулей в одном приложении. Каждый бизнес (кафе, салон, автомойка и другие) получает свой аккаунт, меню, акции и роли сотрудников.
- **Что проверить:** запустите приложение (3 шага ниже) и пройдите сценарий на 5 минут. Демо-данные уже встроены, регистрироваться не нужно.

## Как запустить

Нужен **Python 3.11–3.13** (рекомендуется 3.12). **API-ключ уже настроен в файле `.env`**, вводить его не нужно.

### Windows

1. Установите Python 3.12 с [python.org](https://www.python.org/downloads/) (отметьте **Add python.exe to PATH**).
2. Запустите `setup.bat`. На вопрос про распознавание речи ответьте `n`, если голос проверять не нужно (так быстрее), и `y`, если нужно.
3. Запустите `run.bat`. Приложение откроется в браузере: `http://localhost:8501`.

### macOS / Linux

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Голосовой аудит (необязательно): `pip install -r requirements-audio.txt`. Без него аудит работает по тексту диалога.

## Проверка за 5 минут

На экране входа нажмите кнопку **«Тараз Lezzeti»** (кафе). **Демо-данные уже загружены**, ничего заполнять не нужно: в «Онлайн-продажах» пример переписки с чеком, в Live-Coach готовый аудит, в «Отзывах» разобранный отзыв, в «ИИ-анализе» графики и пример отчёта. Действия из таблицы ниже работают вживую через языковую модель.

| Шаг | Раздел | Что сделать | Что вы увидите |
|---|---|---|---|
| 1 | **Онлайн-продажи** | Напишите: `Сәлем! Один плов и чай, самовывоз, оплата Kaspi` | Бот отвечает на языке клиента, предлагает допродажу, учитывает скидку за самовывоз и выдаёт чек |
| 2 | **Live-Coach** | Вставьте диалог из блока ниже в поле «текст диалога» и нажмите «Запустить ИИ-аудит» | Оценка, критерии, подсказка сотруднику и **упущенная выручка в ₸** |
| 3 | **Отзывы** | Вставьте: `Плов вкусный, но ждали больше часа` | Тональность, тема и готовый вежливый ответ клиенту |
| 4 | **ИИ-анализ** | Выберите отчёт «План на неделю» и нажмите «Сгенерировать отчёт» | Графики выручки и топ-позиций, ИИ-отчёт, который сохраняется и скачивается |
| 5 | **Ассистент** | Нажмите быстрый вопрос «Идеи акций» | Ответ по меню, акциям и цифрам именно этого бизнеса |
| 6 | **Мультиаккаунт** | В меню аккаунта нажмите «Выйти» и войдите как **«Aruzhan Beauty»** (салон). Напишите боту: `Хочу записаться на стрижку` | Те же модули, но бот работает как администратор салона: другое меню, акции и роли |

Диалог для шага 2 (кассир не предлагает допродажи):

```
Кассир: Добрый день! Что будете заказывать?
Клиент: Один плов и лагман, пожалуйста.
Кассир: Плов и лагман. Что-нибудь ещё?
Клиент: Нет, всё.
Кассир: С вас 4 700 тенге. Оплата Kaspi или наличные?
Клиент: Kaspi.
Кассир: Готово, ждите.
```

Логины демо-аккаунтов: `cafe`, `salon`, `wash`; пароль для ручного входа `demo123`. Данные демо-бизнесов вымышленные, пример отчёта в «ИИ-анализе» собран по шаблону (настоящий отчёт создаёт кнопка «Сгенерировать отчёт»). Чтобы вернуть начальное состояние, закройте приложение, удалите файл `qadam.db` и запустите снова. Все данные сохраняются: после перезапуска история чатов, заказы и отчёты остаются на месте.

| Цель трека | Что делает Qadam AI |
|---|---|
| **Зарабатывать больше** | Бот предлагает допродажи и называет акции; Live-Coach показывает, сколько денег упущено и чему учить сотрудников; ИИ-отчёты по продажам подсказывают, что продвигать |

## Что реализовано и чего пока нет

**Реализовано:** пять модулей (продажи, Live-Coach, отзывы, ИИ-анализ, ассистент), мультиаккаунт под разные типы бизнеса, сохранение всех данных в базе SQLite, экспорт данных в JSON, локальная расшифровка речи, тесты слоя данных.

**Честные ограничения MVP:**
- Клиентский чат работает в веб-интерфейсе; интеграций с Instagram, WhatsApp и Kaspi пока нет.
- Оценка упущенной выручки приблизительная: это оценка модели по меню, а не бухгалтерский учёт.
- Показатель «Конверсия ИИ» на экране продаж демонстрационный, а не измеренный.
- Качество ответов зависит от выбранной языковой модели и провайдера.
- SQLite подходит для демонстрации и небольшой нагрузки; для облака планируется PostgreSQL.
- Результатов пилота с реальным бизнесом пока нет.

## Технологии и архитектура

```
Браузер ── Streamlit (app.py) ──┬── Qwen (OpenAI-совместимый API) — чат, аудит, отзывы, отчёты, ассистент
                                ├── SQLite (database.py)          — всё сохраняется
                                └── faster-whisper (локально)     — расшифровка аудио
```

Python, Streamlit, Qwen через OpenAI-совместимый API, SQLite (8 таблиц, данные аккаунтов изолированы), faster-whisper, Plotly. Аудиозаписи обрабатываются на компьютере и не уходят в облако: к языковой модели отправляется только текст диалога и сводные данные. Пароли хранятся в виде хеша (PBKDF2).

## Структура репозитория

```
├── app.py                    # интерфейс, промпты, логика разделов
├── database.py               # слой данных (SQLite)
├── requirements.txt          # зависимости
├── requirements-audio.txt    # зависимости для расшифровки речи (необязательно)
├── setup.bat / run.bat       # установка и запуск на Windows
├── tests/                    # тесты базы данных
└── docs/README-full.md       # полная документация: настройки, база, деплой, безопасность
```

Тесты: `python -m unittest discover -s tests -v`.

## Если не запускается

| Проблема | Решение |
|---|---|
| `No module named 'database'` | `database.py` должен лежать рядом с `app.py` |
| «API-ключ не задан» | Проверьте, что файл `.env` лежит рядом с `app.py`, и перезапустите приложение |
| Ошибка при установке `av` | Нужен Python 3.12, а не 3.14 и новее |
| Не расшифровывается голос | Вставьте текст диалога вручную: аудит работает и без Whisper. Либо `python -m pip install -U av faster-whisper` тем же Python, из которого запущено приложение |
