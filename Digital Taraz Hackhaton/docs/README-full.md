## Зачем это нужно

Малый бизнес теряет деньги там, где этого не видно: сотрудник не предложил допродажу, клиент не получил ответ, отзыв остался без внимания, а цифры лежат в тетрадях и чатах. Qadam AI закрывает эти дыры и показывает потери и рост **в тенге**.

## Возможности

| Раздел | Что делает |
|---|---|
| **Онлайн-продажи** | ИИ-администратор принимает заказы и записи в чате, предлагает допродажи, учитывает акции, выдаёт чек. История чата сохраняется. |
| **Live-Coach** | Аудит диалога сотрудника с клиентом (голос или текст): оценка по пяти критериям, подсказки и **упущенная выручка в ₸**. |
| **Отзывы** | Тональность, тема и готовый ответ клиенту на языке отзыва. |
| **ИИ-анализ** | Дашборд (выручка, средний чек, топ-позиции) и ИИ-отчёты: обзор, продажи, сервис, отзывы, план на неделю. Отчёты сохраняются и скачиваются. |
| **Ассистент** | Персональный помощник владельца: знает меню, акции и цифры бизнеса, помнит диалог, пишет посты и планы. |

Дополнительно: **несколько аккаунтов** (кафе, салон красоты, автомойка, магазин, другое). У каждого свои меню, акции, роли сотрудников и данные, а промпты и подписи интерфейса подстраиваются под тип бизнеса.

## Демо

При первом запуске создаются три демо-бизнеса. Пароль для всех — `demo123`.

| Логин | Бизнес |
|---|---|
| `cafe` | Тараз Lezzeti (кафе) |
| `salon` | Aruzhan Beauty (салон красоты) |
| `wash` | Taraz Wash (автомойка) |

Данные демо-бизнесов вымышленные. Быстрый путь на 5 минут:

1. Войдите в `cafe` и в меню аккаунта (справа вверху) нажмите **«Загрузить демо-данные»**.
2. **Онлайн-продажи:** напишите «Сәлем! Один плов, самовывоз, оплата Kaspi» и посмотрите допродажу и чек.
3. **Live-Coach:** вставьте диалог без допродаж и получите оценку и упущенную выручку.
4. **Отзывы:** вставьте жалобу и получите готовый ответ.
5. **ИИ-анализ:** сгенерируйте отчёт «План на неделю».
6. **Ассистент:** нажмите «Идеи акций».
7. Выйдите и войдите как `salon`: роли, подписи и поведение бота изменились.

## Быстрый старт

Нужен **Python 3.11–3.13** (рекомендуется 3.12). На Python 3.14+ часть пакетов (например, `av` для расшифровки аудио) может не ставиться.

### Windows

1. Установите Python 3.12 с [python.org](https://www.python.org/downloads/) (отметьте **Add python.exe to PATH**).
2. Запустите `setup.bat`: он создаст окружение `.venv`, установит зависимости и создаст файл `.env`.
3. Откройте `.env` и впишите ключ: `QWEN_API_KEY=...`
4. Запустите `run.bat`. Приложение откроется на `http://localhost:8501`.

### macOS / Linux

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env          # затем впишите QWEN_API_KEY в .env
streamlit run app.py
```

### Расшифровка аудио (необязательно)

Нужна только для записи и загрузки голоса в Live-Coach. Без неё аудит работает по тексту диалога.

```bash
pip install -r requirements-audio.txt
```

## Настройка (`.env`)

Ключи в интерфейсе вводить не нужно: всё берётся из файла `.env` (скопируйте `.env.example`).

| Переменная | Обязательно | По умолчанию | Описание |
|---|---|---|---|
| `QWEN_API_KEY` | да | — | API-ключ провайдера (также читаются `XKIRO_API_KEY`, `OPENAI_API_KEY`) |
| `QWEN_BASE_URL` | нет | `https://api.xkiro.com/v1` | Адрес OpenAI-совместимого API |
| `QWEN_MODEL` | нет | `qwen/qwen3.8-max:free` | Имя модели. Если провайдер вернёт «model not found», поправьте здесь |
| `WHISPER_MODEL` | нет | `small` | Модель расшифровки: `tiny`, `base`, `small`, `medium`, `large-v3` |
| `QADAM_DB` | нет | `qadam.db` | Путь к файлу базы данных |

## Как пользоваться

- **Вход.** Демо-аккаунты входят одной кнопкой. Новый аккаунт создаётся на вкладке «Создать аккаунт»: название, тип бизнеса, адрес, меню или прайс (позиция и цена в строке), акции, логин и пароль от 6 символов. Вход запоминается в ссылке на 30 дней.
- **Онлайн-продажи.** Пишите боту как клиент. Когда заказ оформлен, появляется чек, а заказ попадает в журнал и аналитику.
- **Live-Coach.** Запишите голос, загрузите файл (WAV, MP3, M4A) или вставьте текст диалога и нажмите «Запустить ИИ-аудит».
- **Отзывы.** Вставьте отзыв и получите тональность, тему и ответ.
- **ИИ-анализ.** Выберите тип отчёта и сгенерируйте его. Для этого нужны данные: примите заказы или загрузите демо-данные.
- **Ассистент.** Используйте быстрые вопросы или пишите свои.
- **Меню аккаунта** (справа вверху): загрузить или удалить демо-данные, сбросить чат, скачать все данные аккаунта в JSON, выйти.

Если расшифровка аудио не работает, вставьте текст диалога вручную: аудит не требует Whisper.

## Архитектура

```
Браузер ── Streamlit (app.py) ──┬── Qwen (OpenAI-совместимый API) — чат, аудит, отзывы, отчёты, ассистент
                                ├── SQLite (database.py)          — всё сохраняется
                                └── faster-whisper (локально)     — расшифровка аудио, без отправки в облако
```

Аудио расшифровывается **локально**: API провайдера не поддерживает `/audio/transcriptions`. Запись с микрофона (WAV) читается встроенными средствами Python, остальные форматы (MP3, M4A) декодирует PyAV.

```
qadam-ai/
├── app.py                    # интерфейс Streamlit, промпты, логика разделов
├── database.py               # слой данных (SQLite)
├── requirements.txt          # основные зависимости
├── requirements-audio.txt    # зависимости для расшифровки аудио (Whisper)
├── .env.example              # шаблон настроек
├── .streamlit/config.toml    # тема и настройки Streamlit
├── setup.bat / run.bat       # установка и запуск на Windows
├── docs/screenshots/         # скриншоты для README
└── tests/test_database.py    # тесты базы данных
```

## База данных

SQLite-файл `qadam.db` создаётся автоматически рядом с `app.py`. Сервер не нужен, бэкап — копия файла. Режим WAL и внешние ключи включены; данные каждого аккаунта изолированы и удаляются вместе с ним.

| Таблица | Содержимое |
|---|---|
| `accounts` | профили бизнесов, меню или прайс, акции, хеш пароля (PBKDF2) |
| `sessions` | токены входа (30 дней): после обновления страницы входить заново не нужно |
| `orders` | заказы и записи с позициями чека |
| `audits` | ИИ-аудиты диалогов (полный результат в JSON) |
| `feedbacks` | отзывы, тональность, тема, ответ ИИ |
| `chat_messages` | история чата продаж |
| `assistant_messages` | история диалога с ассистентом |
| `ai_reports` | сохранённые ИИ-отчёты |

Старые данные из `accounts.json` и папки `data/` (прежняя версия) переносятся в базу автоматически при первом запуске.

## Деплой

- **Локально или на своём сервере:** `streamlit run app.py`, ключ в `.env`. Диск должен быть постоянным, чтобы `qadam.db` не терялась.
- **Streamlit Community Cloud:** добавьте `QWEN_API_KEY` в *Secrets* (верхний уровень). Файловая система там временная, база может сбрасываться при перезапуске: для демонстрации подойдёт, для постоянного хранения лучше свой сервер или внешняя БД.
- На хостинге с малой памятью Whisper лучше не включать (не ставьте `requirements-audio.txt`): аудит по тексту продолжит работать.

## Безопасность

- Файл `.env` в `.gitignore` и **не должен попадать в репозиторий**. Не публикуйте ключи в чатах, README и скриншотах. Если ключ засветился, пересоздайте его у провайдера.
- `qadam.db`, `accounts.json` и `data/` тоже в `.gitignore`.
- Пароли хранятся только в виде хеша. Демо-пароль `demo123` предназначен для показа: перед публичным использованием удалите демо-аккаунты или смените пароли.
- Вход по ссылке (`?s=...`) работает как «запомнить меня» на 30 дней: не пересылайте адрес из браузера другим людям. Кнопка «Выйти» удаляет токен.
- К провайдеру модели уходят текст диалога и сводные данные аккаунта; аудиозаписи обрабатываются локально.

## Частые проблемы

| Симптом | Причина и решение |
|---|---|
| `No module named 'database'` | `database.py` должен лежать в одной папке с `app.py` |
| «API-ключ не задан» | Создайте `.env` из `.env.example`, впишите `QWEN_API_KEY` и перезапустите приложение |
| Ошибка 401 | Ключ неверный или отозван: проверьте его у провайдера |
| «model not found» | Задайте существующее имя модели в `QWEN_MODEL` |
| Ошибка при установке `av` (`Cython`, `Failed to build 'av'`) | Вы на слишком новом Python (3.14+). Используйте Python 3.12 и `setup.bat` |
| `unexpected keyword argument 'metadata_errors'` | Старая версия PyAV: `python -m pip install -U av faster-whisper` **тем же Python, из которого запущен Streamlit** (приложение выводит точную команду) |
| `404 … /audio/transcriptions` | Провайдер не поддерживает расшифровку: используется локальный Whisper (`requirements-audio.txt`) |
| Первый аудит очень долгий | Идёт скачивание модели Whisper (~500 МБ для `small`). Для слабого ПК задайте `WHISPER_MODEL=base` |
| Кнопка отчёта в «ИИ-анализе» неактивна | Нет данных: загрузите демо-данные или примите заказ |
| Предупреждение про `use_container_width` | Новая версия Streamlit: замените параметр на `width="stretch"` или закрепите `streamlit<1.50` |
| Навигация выглядит как обычные радиокнопки | Разметка Streamlit отличается в вашей версии: обновите Streamlit или откройте issue со скриншотом |
